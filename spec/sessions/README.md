# Sessions

Use these files to carry verified facts from one agent session to the next.

- [HANDOFF.md](./HANDOFF.md) - compact continuation note for the next agent
- `session-XX.md` - numbered session logs. Read the highest-numbered open file first.
- [templates/SESSION_TEMPLATE.md](./templates/SESSION_TEMPLATE.md) - template for new session logs
- [templates/HANDOFF_TEMPLATE.md](./templates/HANDOFF_TEMPLATE.md) - template for handoff notes

Use this folder for verified session facts only.
Do not use it as a transcript archive or a second project specification.
